Comment jouer ?

Choisis une variante

Chaque édition change le nombre de choix, la longueur du code ou la limite d’essais. Les éditions électroniques permettent aussi de choisir la longueur prévue par leur règle.

Trouve le code

Ajoute les pions, chiffres, lettres ou symboles par clic ou glisser-déposer, puis valide ta proposition. Les répétitions sont autorisées.

Lis le résultat

Le premier chiffre indique les valeurs bien placées et le second les bonnes valeurs placées au mauvais endroit.

Respecte la limite de l’édition

Le nombre d’essais donnant des points dépend de la variante. Tu peux continuer après la limite pour trouver le code, mais le score final sera nul.

Facile enfant

En difficulté « Facile enfant », chaque pion reçoit un indice individuel. Secret Search affiche ses flèches alphabétiques quelle que soit la difficulté.
